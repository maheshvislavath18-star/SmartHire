# SmartHire – Django Job Portal

SmartHire is a full-stack Django job portal project where recruiters can post jobs and applicants can apply with resumes.

---

# Features

- User Authentication
- Recruiter & Applicant Roles
- Job Posting System
- Apply Job System
- Resume Upload
- Recruiter Dashboard
- Application Status Management
- Search & Filters
- Responsive UI
- Dashboard Analytics Cards

---

# Tech Stack

- Python
- Django
- HTML
- CSS
- SQLite
