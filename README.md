\# SmartHire – Django Job Portal



SmartHire is a Django-based job portal project where recruiters can post jobs and applicants can apply with resumes.



\## Features



\- User Authentication

\- Recruiter \& Applicant Roles

\- Job Apply System

\- Resume Upload

\- Recruiter Dashboard

\- Application Status Management

\- Search Jobs

\- Dashboard Analytics



\## Tech Stack



\- Python

\- Django

\- HTML

\- CSS

\- SQLite
